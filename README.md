# Geo-Albania

A browser-based Street View explorer that drops you into a random location across Albania.

## What it does

Click **Explore Albania** and get teleported to a Street View location somewhere in Albania. Every click picks a new spot at random.

50+ Locations Including:

- **Tirana**
- **Coastal Cities**
- **Historic Towns**
- **Scenic Roads & Landscapes**

## Notes

This is a personal project built to explore Albania through Street View.

## Misc.
Used Google Embed Api for Streetview.
- [Google Maps Embed API](https://developers.google.com/maps/documentation/embed/get-started)
